# СУМ-11 для Kindle

Тлумачний «Словник української мови» в 11 томах (АН УРСР, 1970–1980) як словник
для Kindle. Довге натискання на слово в українській книжці показує його значення
у спливному вікні.

[English version](README_EN.md)

- **~131 тис. статей**, повний текст СУМ-11 з прикладами вживання.
- **Пошук за формами слова**: «абажуром», «писала» відкривають «абажур»,
  «писати» (≈3,7 млн форм, згенерованих
  [pymorphy3](https://github.com/no-plagiarism/pymorphy3)).
- **Слова на початку речення** («Ганком…») теж знаходяться.
- **Сучасне «ґ»**: у СУМ-11 його немає, але «ґанок», «аґрус», «ґратами»
  відкривають статті «ганок», «агрус», «грати».
- **Будь-який апостроф**: ’ ' ʼ.

## Встановлення

1. Завантажте `sum11.mobi` (~170 МБ) зі сторінки
   [Releases](../../releases/latest).
2. Під'єднайте Kindle до комп'ютера кабелем USB.
   - Старіші Kindle з'являються як звичайна флешка.
   - Деякі новіші моделі підключаються через MTP. На Windows вони
     видні в Провіднику, на Mac потрібна програма
     [OpenMTP](https://openmtp.ganeshrvel.com/) або Android File Transfer.
3. Скопіюйте `sum11.mobi` у папку **`documents/dictionaries`** на Kindle.
4. Безпечно від'єднайте Kindle. Через хвилину-дві словник з'явиться в бібліотеці.
5. Відкрийте українську книжку й утримуйте палець на слові. Якщо у спливному
   вікні відкрився інший словник, торкніться назви словника у вікні й оберіть
   **«СУМ-11: тлумачний словник української мови»**. Kindle запам'ятає вибір.

### Пошук по словнику вручну

На Kindle немає української клавіатури, тож набрати слово для пошуку в самому
словнику важко. Можна додати російську розкладку (Settings → Language &
Dictionaries → Keyboards) і набирати нею слова без і, ї, є, ґ. Головний
сценарій, пошук слова з книжки, працює повністю.

## Часті питання

### «Не знайдено визначення»

- **У книжці вказана не та мова.** Kindle зазвичай обирає словник за мовою з метаданих
  книжки. Якщо українську книжку позначено як російську чи англійську, спливне
  вікно відкриє інший словник. Оберіть СУМ-11 у вікні вручну або виправте мову
  книжки, наприклад у [Calibre](https://calibre-ebook.com/).
- **Слова немає в СУМ-11.** Словник укладено в 1970–1980 роках: новітньої
  лексики, сленгу та багатьох власних назв у ньому немає.
- **Слова немає в даних, з яких зібрано словник.** У джерелі бракує частини
  статей, див. [Відомі обмеження](#відомі-обмеження).
- **Рідкісна форма слова.** Форми генерує pymorphy3. Якщо він не знає слова,
  статтю відкриє лише початкова форма.
- **Словник щойно скопійовано.** Зачекайте, поки Kindle його проіндексує, і
  перевірте, що файл лежить саме в `documents/dictionaries`.

### Як зібрати самому

Потрібні macOS або Linux (на Windows — WSL), `python3`, `curl` і `unzip`.

```sh
git clone https://github.com/volkovskey/kindle-sum11-dictionary
cd kindle-sum11-dictionary
./build.sh            # → sum11.mobi
NO_INFL=1 ./build.sh  # → sum11-plain.mobi, лише головні слова, без форм
```

`build.sh` завантажує tab-файл СУМ-11, ставить залежності з `requirements.txt`
у `.venv`, генерує OPF і HTML скриптом `build_sum.py` у `build/` і збирає
`.mobi` за допомогою [kindling](https://github.com/ciscoriordan/kindling)
(бінарник завантажується автоматично, якщо `kindling-cli` немає в `PATH`).
Повна збірка триває кілька хвилин.

Перевірити, що відкриє Kindle для слова, можна без пристрою:

```sh
work/kindling-cli-mac-apple-silicon lookup sum11.mobi Ганком   # назва бінарника залежить від системи
```

## Підводні камені

Тут описано, на що пішла більша частина часу. Може знадобитися, якщо робите
Kindle-словник для української чи іншої мови, якої kindlegen не знає.

1. **`spell="yes"` ламає kindlegen.** З атрибутом `spell="yes"` в `<idx:entry>`
   kindlegen 2.9 падає на частині українських слів (на «абажур», але не на
   «абак») з `E25007: internal error during index build` /
   `E21012: unknown error while building index`. Мова (`uk`/`ru`) і форми слів
   тут ні до чого. Причину знайдено бісекцією до однієї статті. Рішення —
   прибрати `spell="yes"`. Kindle однаково не перевіряє правопис української.

2. **Зібраний kindlegen словник не працює на пристрої.** Він збирається, але
   пошук з книжки нічого не знаходить, а пошук у словнику завжди відкриває першу
   статтю.

   *Причина.* Kindle шукає слово двійковим пошуком у відсортованому індексі й
   порівнює символи за власною фіксованою таблицею ваг. Кирилиця в ній іде за
   кодами Unicode, а апострофи й дефіс не враховуються. kindlegen для мови `uk`
   записує індекс через свою таблицю ORDT і сортує за власними правилами, у яких
   «е» стоїть перед «б», «в», «г». Тому «аерарій» опиняється перед «абажур», а
   «алея» перед «албанець». Двійковий пошук на пристрої з'їжджає й не доходить
   до потрібного слова. Готовий українсько-англійський словник іншого автора,
   зібраний kindlegen, має той самий порядок.

   *Як знайшли.* Розібрали індекс готового `.mobi` за допомогою
   [KindleUnpack](https://github.com/kevinhendricks/KindleUnpack) і прогнали
   симулятор пошуку з kindling (`kindling-cli lookup`): на файлі від kindlegen
   «абажур» і «алея» не знаходяться, бо «index is not stored in the order its
   search follows».

   *Рішення.* Збирати за допомогою [kindling](https://github.com/ciscoriordan/kindling).
   Це сумісна заміна kindlegen, яка сортує індекс у тому порядку, у якому шукає
   Kindle. Для неї `<x-metadata>` (з `DictionaryInLanguage`) має бути
   **всередині** `<metadata>`, як у специфікації Amazon. Інакше kindling не
   розпізнає словник і збирає звичайну книжку.

3. **Велика літера.** Для українського словника Kindle не переводить торкнуте
   слово в нижній регістр (на відміну від російського), тому «Ганком» на початку
   речення не знаходило «ганок». Рішення — індексувати кожну форму ще й з великої
   літери. Індекс зростає вдвічі (з 1,86 до 3,7 млн форм).

4. **«…» у головних словах.** СУМ-11 має статті-префікси на кшталт «авіа…»,
   «авто…». Трикрапку прибрано з `value` головного слова (`<idx:orth value="авіа">`),
   щоб у ньому було чисте слово. Це було серед підозрюваних причин помилок
   kindlegen, але винним виявився `spell="yes"` (пункт 1). На пошук на Kindle «…»
   не впливає, бо пристрій при порівнянні її ігнорує. Статті шукаються як «авіа»,
   «авто».

5. **«ґ».** Радянський СУМ-11 пише «ганок», «грунт», а сучасні книжки — «ґанок»,
   «ґрунт». Для кожної леми pymorphy3 з «ґ», чий варіант із «г» є головним
   словом СУМ-11, її ґ-форми додаються до цієї статті: 285 лем, 7190 форм.

## Відомі обмеження

Частини статей СУМ-11 немає в самих даних, з яких зібрано словник. Їх немає в
жодному форматі релізу-джерела (перевірено Tabfile, Stardict, Json, Csv,
StardictTextual, DictOrgSource: скрізь по 127 068 записів):

- **усі слова на «п’я…»**: «п’ять», «п’ятниця», «п’яний», «п’ятак», «п’явка»…;
- **«грунт», «гудзик», «дзига»** (є лише похідні: «грунтовий», «гудзиковий»), а
  отже, і «ґрунт», «ґудзик».

Якщо знаєте повніше відкрите джерело СУМ-11, відкрийте
[issue](../../issues).

Омоніми (кілька статей з одним заголовком, як «рентген», або форма, що
збігається з іншим словом, як «свари» від «свара» і «сварити») відкривають одну
зі статей. Решту видно, якщо в спливному вікні перейти до повного словника.
